# 双语题录 Bilingual Records — 0.2.0

目标环境：Zotero 9.0.x–10.0.x（接口核查针对 9.0.6 和 10.0.7），Word 的 Zotero 插件。

一条文献保存两套作者、标题、刊名等信息，年份、卷期、页码、DOI、PDF 共用。每篇 Word 文档保存自己的题录语言。插件在该文档引用引擎读取数据时，将对应语言的信息映射为标准 CSL 字段，无需修改期刊 CSL。

## 安装与使用

1. 先备份 Zotero 文献库，用测试条目和 Word 副本验证原型。
2. Zotero → 工具 → 插件 → 齿轮 → 从文件安装插件，选择 `dist/bilingual-records-0.2.0.xpi`，按提示重启。
3. 在 Zotero 主列表选中一条文献，右键 → 编辑双语题录；原工具菜单入口也保留。
4. 填写中文和英文标题、作者、刊名。作者一行一位，例如 `Zhang | San`。优先采用论文首页或期刊网站提供的英文信息。
5. Word → Zotero → Document Preferences，照常选择期刊样式并确认，随后会出现插件的题录语言选择窗口，选“英文题录”。
6. 点击 Refresh；保存 Word 文件。要换回中文，重新打开 Document Preferences 并选中文。换投稿期刊也照常在这里选样式。

原始题录模式完全使用原字段。中文／英文模式读取 Extra 中独立保存的双语数据。常规字段和附件不被改写。

## 当前边界

- **0.1.2 已在本机 Zotero 9.0.6 的独立配置和空数据库中通过实际安装、启用及启动测试。** 0.1.3 在同一隔离环境中进一步验证：编辑窗口载入完成，14 个双语输入框生成，中文与英文初始值正确，修改英文标题后点击保存可返回结果。测试使用 headless DOM 检查，尚未目视验收布局或验证真实 Word 引用流程。
- 原型只编辑作者和主要文本字段，支持离线生成中文作者拼音；尚未提供双语编辑者、译者、批量录入、自动抓取或标题自动翻译。
- 没有配置双语数据的条目使用原题录；这不是全库自动英文化。配置了双语的条目若缺所选语言的标题、作者或原条目已有的刊名，会报错，避免无提示地混用中英文。
- 语言设置按文档保存，当前使用独立选择窗口；没有在 Word 功能区新增按钮。取消插件窗口仅保留原有题录语言，不撤销此前确认的 Zotero 期刊样式变更。
- 仅支持可访问 `style.sys.retrieveItem` 的引用引擎。依赖 Zotero 内部接口，升级到其他主版本前需重新验证；安装包支持 9.0.x–10.0.x。
- 仅嵌入 Word、当前文献库没有对应条目的记录暂不支持中文／英文模式，会明确报错。换电脑时需同步文献库并安装插件。
- 不保证与 CNE、其他修改引用引擎的插件兼容。原型测试时请不要同时启用此类插件。
- 禁用插件不会删除 Extra 双语数据或文档语言标记，但之后刷新将按 Zotero 原字段输出；已有排版文本不会自动改变。
- 双语功能在本地执行，姓名拼音库 pinyin-pro 3.27.0 随 XPI 打包并附 MIT 许可，无需 API 或联网。Zotero 强制插件声明 HTTPS 更新地址；当前使用保留的无效域名 `https://example.invalid/bilingual-records/updates.json` 占位，未提供自动更新服务。Zotero 自身执行更新检查时可能尝试连接该地址并失败，升级需手动安装新 XPI。XPI 不包含测试源码、引用引擎、第三方样式或任何远程代码。
- 0.1.6 在使用英文题录输出中文来源文献时，自动在参考文献条目末尾追加 `(in Chinese)`。根据原题录的语言判断中文来源；若语言为空，则用原始标题中的汉字推断。显式填写非中文语言时不推断；不凭英文标题或拼音作者猜测。选择英文题录不表示原论文语言变成英文。

日常操作：右键文献 → 编辑双语题录。期刊论文的英文刊名为空时，打开窗口即按中文刊名匹配对照表；也可点击“补全英文刊名（仅补空白）”。已有英文刊名不覆盖。未知刊名不猜测、不调用在线翻译。匹配结果只在编辑窗口，点击文献保存后才写入条目。

维护入口：编辑窗口下方“更多”→“管理刊名对照表”。默认折叠，作为二级功能。支持搜索、新增、修改、删除和可选英文缩写。

批量维护：在管理窗口展开“批量导入／导出”，从表格复制 2～3 列（中文刊名、英文刊名、可选英文缩写）后粘贴导入。导入先合并当前编辑表，重复中文刊名会提示修正；点击“保存对照表”后才写入设置。导出生成可复制的三列制表符文本，便于自行保存备份。

保存位置：Zotero 本机设置 `extensions.zotero.bilingualRecords.journals.v1`，独立于当前文献保存，取消文献编辑不会撤销已明确保存的对照表。升级插件保留设置；不会自动同步到其他电脑，可导出后在其他电脑导入。并发编辑同一对照表时，过期窗口会拒绝覆盖新版本。

匹配采用中文正式刊名的精确匹配，规范空格和全半角括号，不模糊匹配相似刊名。图书等非期刊论文不自动补全刊名。

## 0.1.3 空白窗口修复

根因一：直接用 jar:file 安装包路径创建特权窗口，实测停留在 about:blank，文档未初始化。改为通过 registerChrome 注册 content 路径，使用 chrome://bilingual-records/content/editor.xhtml 打开。

根因二：跨作用域传入的窗口参数需要 wrappedJSObject 解包；未解包时 io.data 不可读。

根因三：chrome XHTML 中该脚本执行时表格节点尚不存在，defer 未达到原先预期。改为在 DOMContentLoaded 后构建表单，并在初始化异常时显示具体错误。
